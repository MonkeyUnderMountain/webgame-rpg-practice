## 六个交互块

| 块 | 作用 |
| --- | --- |
| About | 个人身份、近况、联系方式 |
| Notes | 数学笔记、文章、阅读记录 |
| News | 研讨班、动态、公告 |
| Side Quests | 项目、小说、兴趣链接 |
| Research | 论文、研究方向、正在做的题 |
| Enter | 进入像素 RPG 的入口 |
