# 屏幕比例适配与 Tiled 精修子路线图

这份子路线图细化 [ROADMAP.md](ROADMAP.md) 阶段一的「场景扩展与多比例适配」和阶段二的「地面、墙面 Tiled 精修」，拆成可逐步推进、每步独立验收的小阶段。

## 已定方案原则

- **扩屏架构（方案 A）**：保持核心 `640×360` 书房与所有家具、热点、光影坐标完全不动；外围通过 **4 个同倍率对齐的 Tiled 延展带**（上墙、下石基、左竖带、右竖带）按同一 `scale` 无缝铺满任意屏幕比例。
- **显示策略（策略 1）**：桌面 16:9 下核心 `640×360` 尽量占满整屏（视觉最大化）；非 16:9（16:10 / 4:3 / 21:9 等）不再裁切家具，多出的空间由四周延展带自然补齐；手机竖屏（`<= 760px`）保持现有上下文档流。
- **调色板与精度**：墙、地、台阶均以 1× 逻辑像素制作（优先沿用房间 23 色索引调色板体系），统一按 3× Nearest-Neighbor 导出。
