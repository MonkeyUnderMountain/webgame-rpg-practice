## 阶段一：v1.0 上线收尾（可公开发布）

> 目标：统一 UI 与画面风格，解决不同屏幕比例的适配，替换占位资源并完成发布前检查。

### 1. UI 风格与屏幕适配
- [ ] **整理整体 UI 与美术风格**：统一顶栏、底栏、热点标签等界面元素的视觉语言
- [ ] **调整弹窗美术风格**：让阅读弹窗与门外弹窗的视觉风格与侧视像素书房更协调
- [ ] **稍稍扩展场景以适应不同屏幕比例**：适当扩展核心区域外围的墙面/地面边界，避免宽屏或窄屏裁切家具或留黑过多
- [ ] **多分辨率与触控微调**：测试桌面偏扁/偏窄窗口下顶栏与底栏是否遮挡热点（调整 `src/study.ts` 的 `desktopInsets`），并评估移动端 `14×13` 便签热点的点击体验

### 2. 资源替换与发布检查
- [ ] **生成完整合成预览图**：在导出流程中生成含完整家具的预览图供 `og:image` 使用，避免分享卡片显示空石墙
- [ ] **替换门外占位图**：用真实风景照或像素插画替换 `public/art/study/outside.svg`，并更新 `index.html` 中 `#door-dialog` 的图注
- [ ] **压缩背景音乐体积**：将 `public/audio/study/medieval-abbey.mp3`（当前 ~5.4 MB）转码或裁剪到 ~1.5 MB 左右，加快点击后的首播速度
- [ ] **统一文案、栏目与文档细节**：审校 `content/home/` 下五个栏目的外链与近况；对齐导航与热点大小写（`Side quests` / `Side Quests`），同步 `docs/EDITING_GUIDE.md` 中关于窗景的描述

## 阶段二：让书房“活”起来（美术深化与微交互）

> 目标：在保持主页清爽克制的前提下，打磨像素美术细节，加入轻量的趣味交互与个人数学印记。

### 1. 场景微交互（零件多状态与彩蛋）
- [ ] **黑板多幅数学图切换**：在 `30_chalkboard` 增画 2–3 幅与研究方向相关的草图（如代数几何交换图、射影空间动力系统示意等），点击粉笔槽循环切换并记住状态
- [ ] **彩蛋物件交互**：为书柜黄铜四面体、桌上翻开的书、显示器等物件增加轻量的点击反馈或趣味批注
- [ ] **窗外轻度动态氛围**：在窗景中加入缓慢飘动的云层等细微循环动效

### 2. 美术细节与听觉打磨
- [ ] **像素画与 Tiled 设计迭代**：微调像素画风、光影与材质细节，完善地面与墙面的 tiled 拼接设计（同时服务于不同屏幕比例的画面延展）
- [ ] **界面音效（可选）**：为翻开弹窗、点击便签等操作补充极轻的环境/界面音效，并跟随静音状态
